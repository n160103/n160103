- Turn existing course material (a book, a folder, or older modules) into a clear e-learning path
- Make short instructional videos: script, visuals, voice-over, and edit, in the style of the course
- Build interactive practice inside the course itself, so learners don't need a separate website
- Keep official training content complete and accurate — I make it easier to follow, I don't rewrite the substance
